## 1. BA check

BA: `product-manager` + `design-ux-architect` + `design-ui-designer`, 01/11/2026.

**Bối cảnh:**

Người dùng bàn phím Tab tới ô ngày của lịch tháng trên Dashboard, hoặc tới link mã lệnh trong hộp
"lệnh trong ngày", nhưng không thấy mình đang đứng ở đâu (WCAG 2.4.7). Cơ chế đã xác nhận trong CSS
build thật:

```
.outline-none { --tw-outline-style: none; outline-style: none }
.focus-visible\:outline-2:focus-visible { outline-style: var(--tw-outline-style); outline-width: 2px }
@property --tw-outline-style { inherits: false; initial-value: solid }
```

`focus-visible:outline-*` chỉ hỏng khi đi chung `outline-none` (hoặc `outline-hidden`) trên cùng
phần tử. Test jsdom chỉ thấy tên class nên vẫn xanh. K-05 đã gặp và sửa lỗi này ở `AuthLinks.tsx`.
